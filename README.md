# AI Hallucination Research

Research planning for benchmarking and mitigating object hallucination in multimodal language models, with a focus on medical devices in chest X-rays.

Start with [HANDOFF.md](HANDOFF.md) for the current project state, then read [STAGE1_PLAN.md](STAGE1_PLAN.md) and [PROTOCOL.md](PROTOCOL.md). [PROGRESS.md](PROGRESS.md) records completed work and decisions; [STRATEGY.md](STRATEGY.md) describes the longer research program.

- `drafts/`: correspondence drafts and the IRB protocol summary.
- `research/`: literature digests, design logs, and the archived general-domain strategy.

This repository currently contains planning and research documents. It does not contain an implemented evaluation pipeline or experimental results.

Keep this repository private, as required by the project protocol. Credentials, downloaded datasets, model weights, RANZCR labels and identifiers, and image mapping files must remain outside Git. See the data terms in [PROTOCOL.md](PROTOCOL.md).
